# About TeamForge

## Why it exists

Could two Unity Editor instances collaborate more directly while people are
working in them? TeamForge began with that question.

Git and Unity Version Control preserve project history. TeamForge explores the
space between commits: seeing a collaborator, sharing selected Scene changes,
coordinating ownership and getting another machine into the project.

It is an early open-source experiment for friends, students, independent
developers and small teams. The public source and development capture make the
work inspectable; they do not make it production ready.

## Help shape it

Unity and C# review, networking feedback, failure-case testing, security review,
documentation and translation work all help make the experiment more useful.
Start with the [contributing guide](../.github/CONTRIBUTING.md) or
