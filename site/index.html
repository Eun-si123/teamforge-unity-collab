TeamForge is an open-source real-time collaboration project for the Unity Editor. It focuses on the awkward part between source control commits: seeing each other, synchronizing supported Scene edits, avoiding collisions, and getting another machine into the project.

A narrow job, done inside Unity.

TeamForge does not try to replace Git or Unity Version Control. It is about the moments when two people are already inside the Editor and need better shared context.

Why it exists.

The project started while building a Unity game with a friend: could two Editor instances collaborate more directly without pretending source control solves every live collaboration problem?

That small question turned into an experiment in shared Editor state, conflict control, and project bootstrap for friends, students, indie developers, and small teams.

한국어

TeamForge는 Unity Editor 안에서 실시간 협업을 실험하는 오픈소스 프로젝트입니다. 접속 상태, Transform 동기화, 같은 Scene의 Hierarchy 협업, 잠금/소유권, P2P 프로젝트 부트스트랩과 전송을 하나의 흐름으로 연결하는 것을 목표로 합니다.

현재는 소스 공개 초기 프리뷰 단계입니다. 일반 사용자에게 설치 가능한 안정적인 Alpha를 권장하는 상태는 아니며, 중요한 프로젝트에 적용하기 전 현재 검증 상태와 제한사항을 확인하는 편이 좋습니다.
