TeamForge is an open-source real-time collaboration project for the Unity Editor. It focuses on the awkward part between source-control commits: seeing each other, sharing supported Scene edits, avoiding collisions, and getting another machine into the project.

Current state / 03

Useful now. Not pretending to be finished.

Working pieces exist and are tested, while distribution and field validation still come before a general alpha recommendation.

Available

Public source

Unity package, server, Project Peer, launcher, tests, architecture notes, and development records can be inspected directly.

Automated

Repository CI

Server, Project Peer, runtime-loader, and Windows launcher checks run through GitHub Actions.

Stabilizing

Two-PC workflow

The Host → Guest → transfer → activation → realtime path exists, but the exact field-validation gate still needs to close.

Not yet

General installable alpha

No packaged build is currently recommended to general users. A Git URL is not being treated as a complete end-user release.

Enabled

Security automation

Dependency, secret, and code scanning support review without pretending automated scans equal an independent audit.

Not audited

Production trust

Important projects should still be backed up, and testing should prefer disposable or recoverable projects.

Product scope / 04

The live layer between commits.

TeamForge does not try to replace Git or Unity Version Control. It works on the moments when two people are already inside the Editor and need shared context.

Origin / 06

It started with two Editors and one question.

Could two Unity Editor instances collaborate more directly without pretending source control solves every live collaboration problem?

That small question turned into an experiment in shared Editor state, conflict control, and project bootstrap for friends, students, indie developers, and small teams.

한국어 / 07

Unity Editor 안에서 같이 작업하기.

TeamForge는 Unity Editor 안에서 실시간 협업을 실험하는 오픈소스 프로젝트입니다. 접속 상태, Transform 동기화, 같은 Scene의 Hierarchy 협업, 잠금/소유권, P2P 프로젝트 부트스트랩과 전송을 하나의 흐름으로 연결하는 것을 목표로 합니다.

현재는 소스 공개 초기 프리뷰 단계입니다. 일반 사용자에게 설치 가능한 안정적인 Alpha를 권장하는 상태는 아니며, 중요한 프로젝트에 적용하기 전 현재 검증 상태와 제한사항을 확인하는 편이 좋습니다.
