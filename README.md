# TeamForge — Unity Real-time Collaboration

> 🚧 **Work in Progress / Early Public Preview**
>
> This repository is currently being prepared. TeamForge is still under active development, and the public documentation, demos, and feedback materials are being added gradually.
>
> **This is not a public source-code release yet.** Please don't treat the current repository contents as a finished product or final specification.

TeamForge is an experimental collaboration tool for the Unity Editor, exploring real-time multi-user editing and easier project sharing between developers.

## What is being prepared?

- A short explanation of the problem TeamForge is trying to solve
- Current and planned collaboration features
- Demo GIFs / videos
- A comparison with existing Unity collaboration workflows
- A public feedback area for Unity developers
- Early testing / alpha information

## Why is this repository public already?

I'm using this repository to gather early feedback and find out whether Unity developers would actually find this kind of workflow useful before presenting it as a finished project.

If you happen to find this repository early: welcome! 👋 More information is coming soon.
