# M4 recovery of shared primitive deletion requests

Convergence Agent owns `agent/teamforge/m4-primitive-delete-recovery-20261121`
in a separate worktree based on [#584](https://github.com/Eun-si123/teamforge-unity-collab/pull/584)
at `016802cf63aa19a2244db41a0e1980196451d9ec`. The hourly task continues its
independent field scope.

The existing explicit delete command records a childless Cube or Sphere
before sending in durable mode. Offline use against a previously verified
Session records the request without changing the native Scene. The inbox keys
it by signed Project, durable Session lineage, Scene, logical identity,
creation revision and the saved alias when available. A current native leaf,
shared Collider binding, live lease and reviewed Session revision are required
before submission. The existing atomic primitive transaction is reused.

The owned WebSocket fixture holds both origin receipts for a committed deletion
and checks the two authoritative tombstones on an independent peer. Unity CI
also requires an offline archive, save/reopen, stale review refusal, and an
Editor reconnect that reconciles the accepted deletion without sending it again.
The PR records exact results. New installers and physical multi-Editor Windows
LAN evidence are separate.
