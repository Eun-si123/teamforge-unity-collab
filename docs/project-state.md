# TeamForge project-state pointer

This file is retained for compatibility with older links, but it is **no longer an independent current-state source**.

Use the following canonical documents instead:

- **[STATUS.md](STATUS.md)** — what is implemented, validated, blocked, or unsupported now;
- **[`../release-contract.json`](../release-contract.json)** — exact current product/runtime/protocol contract;
- **[architecture.md](architecture.md)** — current as-built topology, authority, identity, and trust boundaries;
- **[ROADMAP.md](ROADMAP.md)** — planned direction, not current implementation facts;
- **GitHub Issues** — detailed live bug discussion and issue state.

## Historical snapshot

The previous `project-state.md` was a dated engineering-state snapshot and duplicated a large amount of `STATUS.md` information. Keeping both documents current caused them to drift as stabilization work moved quickly.

The pre-restructure snapshot remains available in repository history at the branch base commit:

[Project-state snapshot before documentation restructuring](https://github.com/Eun-si123/teamforge-unity-collab/blob/5fdebda8c91e3c858e894356eb4bb735bbc34885/docs/project-state.md)
