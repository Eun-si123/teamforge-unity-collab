# توافق TeamForge

تصف هذه الصفحة **حدود التوافق وبنية الشبكة للقارئ**.

- اختيارات المنتج/runtime/البروتوكول الدقيقة → [`../release-contract.json`](../release-contract.json)
- التحقق والجاهزية الحاليان → [STATUS.md](STATUS.md) (الإنجليزية)
- هوية الحزمة → [`../builds/README.md`](../builds/README.md) + قيمة SHA-256 الدقيقة لأصل Release

لا تكرر أرقام تصحيحات الأدوات وruntime سريعة التغير في عدة مستندات؛ عقد الإصدار هو مرجعها.

## قبل الاختبار

استخدم مشروعًا يمكن الاستغناء عنه واحتفظ بنسخ احتياطية. TeamForge معاينة عامة مبكرة؛ يحدد [STATUS.md](STATUS.md) حدود التحقق الميداني. يفصل الجدول بين المنصة المستهدفة بالحزمة ومتطلبات المصدر والبناء.

لم تُحدد بعد متطلبات CPU وRAM وGPU والقرص وعرض النطاق وزمن الاستجابة الدنيا باختبارات مضبوطة. نجاح تشغيل نموذج أولي ليس توصية بالحد الأدنى من العتاد.

يجب أن يصل Guest إلى Server المُعد وإلى نقطة Project Peer التي يعلنها Host. الدعوة الموقعة لا تنشئ إمكانية الوصول عبر الشبكة. استخدم الجهاز نفسه أو LAN قابلة للوصول أو VPN مُدارة؛ لا يُوفر عبور تلقائي عبر الإنترنت ولا relay.

## المنتج والبروتوكول

تتحرك المكونات كخط منتج متوافق واحد، لا كمزيج مستقل من إصدارات Server/Project Peer/Launcher/الحزمة. تفصل البنية بين:

- صلاحية التعاون الفوري عبر WebSocket الخاص بـServer المُعد؛
- تنسيق التهيئة الأولية للمشروع والبيانات الوصفية؛
- نقل بيانات Project Peer المباشر؛
- سلامة Runtime الخاص بـHost/Guest وLauncher في الحزمة.

تكون تغييرات البروتوكول/المخطط إضافية فقط إذا بقيت الدلالات الحالية متوافقة. الأرقام الدقيقة في `release-contract.json`. لا تخلط بيانات manifest أو ملفات Runtime/Launcher الثنائية من مرشحين مختلفين لمجرد تطابق رقم المنتج الظاهر.

## Unity

الخط المدعوم حاليًا هو **Unity 6000.3**. لا يُعد تصحيح Editor مُتحققًا منه إلا بوجود دليل مسجل للمصدر/المرشح المقصود. أحدث تصحيح Unity ليس مختبرًا أو مدعومًا تلقائيًا. اختيار Editor المختبر في `release-contract.json`، وملخص الأدلة في [STATUS.md](STATUS.md).

## المطورون وruntime

على مطوري المصدر استخدام نطاقات Node/npm/.NET/الأدوات المحددة في العقد وإعدادات lock/build بالمستودع. هذه **متطلبات المصدر والبناء** وليست متطلبات التثبيت المعتادة للمستخدم النهائي لمسار Host/Guest المعبأ، الذي يستخدم runtime مرفقًا/مستقلًا وفق العقد. عائلة runtime/سلسلة أدوات رئيسية جديدة تحتاج قرار توافق وتحقق مقصودين؛ نجاح التثبيت على جهاز واحد لا يكفي.

## بنية الشبكة المدعومة

- WebSocket الخاص بـServer TeamForge المُعد لصلاحية الوقت الفعلي؛
- نقل Project Peer عبر HTTP مباشرة على الجهاز نفسه أو LAN قابلة للوصول أو VPN مُدارة؛
- وضع صريح للجهاز نفسه عبر loopback فقط؛
- استماع خارج loopback مع مصادقة وعنوان مضيف محدد معلن لـGuest؛
- مسار Windows Host/Guest المعبأ مع Runtime مرفق تم التحقق منه.

لا تُوفر حاليًا كبنية مدعومة: WebRTC / RTCDataChannel؛ ICE / STUN / TURN؛ عبور NAT تلقائي؛ relay/انتقال نقل احتياطي تلقائي؛ اكتشاف الأقران تلقائيًا؛ صلاحية وقت فعلي بلا خادم/مضمنة؛ نشر على الإنترنت العام غير الموثوق بنظام كامل لهوية المستخدم والتفويض.

تعني `P2P` هنا **نقل بيانات Project Peer مباشرة**، وليس اتصال P2P تلقائيًا عبر الإنترنت.

## جدول المنصات

| المجال | الحالة |
| --- | --- |
| Runtime Windows x64 المرفق / Guest Launcher | اتجاه الحزمة الحالي؛ المرشح الدقيق ما زال خاضعًا لشروط STATUS الميدانية |
| Unity 6000.3 | خط Unity الحالي |
| تصحيح Unity الدقيق المسجل | `release-contract.json` وأدلة STATUS |
| تصحيحات Unity 6000.3 الأخرى | تحتاج إعادة تحديد خط أساس/تحقق مستقل قبل وصفها بالمختبرة |
| Launcher مستقل على macOS/Linux | لا يوجد مرشح حالي مكافئ معبأ |
| Docker/Compose | خيار مصدر/خادم، لا مسار Host المعبأ المعتاد ولا شرط الإصدار الحالي |
| Authenticode | حالة التوزيع/التوقيع في STATUS ووثائق الأصل الحالي |

## التخزين المُدار على Windows في المصدر الحالي

يتطلب المصدر الحالي جذرًا مُدارًا محليًا على قرص ثابت NTFS/ReFS لقفل هوية المشروع في Windows. تُرفض الجذور الشبكية أو غير المتاحة أو غير المتحقق منها وفق fail-closed. هذا شرط تخزين TeamForge، وليس شرطًا عامًا جديدًا لمشروعات Unity. راجع [STATUS.md](STATUS.md) لحدود المصدر/المرشح المنشور و[التنفيذ المسؤول](../project-peer/src/project-identity-lock.mjs).

## الادعاءات والتاريخ

تنطبق تقارير المراحل والعمل والاختبارات التاريخية على المصدر/الأصل الذي سجلته. تشابه رقم المنتج لا يجعلها دليل توافق حاليًا. عندما تلزم هوية البايتات الدقيقة، استخدم اسم أصل Release + SHA-256 بدل رقم المنتج وحده.
