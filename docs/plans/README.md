# Documentation plans

This directory holds **execution plans**, not current product truth and not proof that an implementation exists.

- `active/` — proposed, active, or paused plans that still guide work.
- `completed/` — completed, cancelled, or superseded plans retained for implementation archaeology.

A plan should state its status, last review date, intended outcome, scope/non-goals, required evidence, completion criteria, and tracking Issue/PR when one exists.

When a plan finishes, update the current canonical documents that actually changed, record the evidence that was obtained, extract durable decisions/lessons when warranted, and move the plan out of `active/`.

For current project facts, use [../README.md](../README.md) and its question-based routing table. For documentation governance, use [../DOCUMENTATION_GUIDE.md](../DOCUMENTATION_GUIDE.md).
