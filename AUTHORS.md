# TeamForge Authors and Credits

## Original project creator

**TeamForge was originally conceived, initiated, and developed as a project by [Eun-si123](https://github.com/Eun-si123) / BlackProtogen.**

The original creator's role includes, among other things:

- defining the original TeamForge concept and goals
- deciding product direction and requirements
- designing and refining collaboration workflows
- deciding which features should be built and how they should behave
- integrating and evaluating implementations
- running real Unity test environments
- reproducing bugs and collecting failure cases
- repeatedly testing and validating behavior
- making final project and release decisions

TeamForge has been developed with **substantial AI assistance**, including AI-assisted and AI-generated implementation and documentation. That assistance is disclosed openly and should not be interpreted as a claim that every line of code was manually authored by the original creator.

At the same time, using AI does not erase the history of who initiated, directed, assembled, tested, maintained, and made the project decisions behind TeamForge.

## Contributors

TeamForge welcomes additional contributors.

People who contribute code, tests, documentation, security reviews, bug reports, designs, translations, or other meaningful work should receive appropriate credit for their own contributions.

Git history, pull requests, issues, and review history are important records of contribution. As the project grows, notable contributors may also be listed here.

**No contributor's work should be falsely attributed to somebody else, and the original TeamForge project should not be falsely represented as having originated from a later fork.**

See [CONTRIBUTING.md](.github/CONTRIBUTING.md) for ways to help and [NOTICE](NOTICE) for the attribution/origin terms that accompany the project's AGPLv3 licensing.
